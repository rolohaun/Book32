Flashing from Linux?

Linux needs a little setup before a browser can use the device's USB serial port. Do these once:

  1. Use Chrome, Chromium, or Edge. Firefox does not support Web Serial. Snap Chromium (the default on Ubuntu) also needs USB access: sudo snap connect chromium:raw-usb. Flatpak browsers need device access too, for example flatpak override --user --device=all com.google.Chrome, or install the browser's .deb or .rpm instead.
  2. Give your account access to serial ports. Run sudo usermod -aG dialout $USER (on Arch Linux the group is uucp), then log out and back in, or restart. Running groups should now list dialout.
  3. Stop ModemManager while flashing. It can grab new USB serial devices and break the connection: sudo systemctl stop ModemManager. It starts again after a restart.
  4. Close anything else using the port, such as a serial monitor, the Arduino IDE, or PlatformIO.
  5. Check that Linux sees the device. With it plugged in, ls /dev/ttyACM* /dev/ttyUSB* should list a port. If nothing shows up, try another data-capable cable or put the device in download mode (hold BOOT, tap RESET, release BOOT).
